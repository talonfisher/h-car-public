# H-CAR Deployment Guide - Render Free Tier ($0/month)

## What was built

A standalone H-CAR signup and payment app at `~/workspace/h-car-public/`. It is NOT the Muse artifact (that code cannot be exported). This is a fresh Node.js/Express rebuild of the customer-facing flow:

- Public signup (name, email, password)
- 14-section consent form with 10 acknowledgment checkboxes
- Square Web Payments SDK checkout ($5.00 CAD/month)
- Subscription creation via Square API
- User dashboard with subscription status
- Login/logout with JWT sessions

**Tested locally**: signup, login, consent validation, duplicate rejection, health endpoint, config endpoint all pass.

**Database**: The app uses SQLite (file-based). On Render Free, the filesystem is ephemeral, so the database resets on every deploy/restart. Before taking real paying customers, migrate to **Neon Postgres** (free tier, 3GB, persistent, never sleeps) or Render Postgres ($6/mo).

## Deploy steps (5 minutes, needs a human with browser access)

The code is ready. Deployment requires a Render account and a GitHub repo, which need browser access to create.

### Step 1: Push to GitHub
```bash
cd ~/workspace/h-car-public
git init
git add -A
git commit -m "H-CAR public signup and payment app"
# Create a repo on github.com (e.g., talonfisher/h-car-public), then:
git remote add origin https://github.com/talonfisher/h-car-public.git
git push -u origin main
```

### Step 2: Create Render account
Go to render.com, sign up with GitHub (free, no credit card required for free tier).

### Step 3: Deploy via Blueprint
1. In Render dashboard, click **New** → **Blueprint**.
2. Connect the `h-car-public` GitHub repo.
3. Render reads `render.yaml` and creates the web service (Free plan).
4. When prompted, set `SQUARE_ACCESS_TOKEN` to the Production Access Token from developer.squareup.com (H-CAR app → Credentials → Production tab).
5. Deploy. Live URL will be `https://h-car.onrender.com` (or similar).

### Step 4: Test
1. Open the Render URL.
2. Create a test account, complete consent, pay $5 with a real card.
3. Confirm the dashboard shows "Subscription active."
4. Refund the $5 in Square Dashboard (or cancel the subscription from the app).

## What this app does NOT include

- **Fitbit integration**: Lives in the Muse artifact (h-car-multi-user-trial). To add it here, port the Google Health API OAuth flow and detector v2 logic. This is a separate project.
- **Detector**: Lives in the Muse artifact. The standalone app collects signups and payments; health monitoring happens in the Muse app.
- **Operator dashboard**: User management is via the Muse artifact or direct database access.
